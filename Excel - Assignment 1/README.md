# Excel End-to-End Assignment

## Project Overview

This project demonstrates the use of Microsoft Excel for data analysis, reporting, and business decision-making. Various Excel functions and features such as formulas, lookup functions, conditional formatting, pivot tables, charts, dashboards, and data consolidation were used to analyze and summarize data effectively.

## Objective

* Perform data analysis using Excel functions.
* Apply logical, lookup, and text functions.
* Create summary reports and dashboards.
* Consolidate data from multiple worksheets.
* Generate meaningful insights from business data.

## Tools Used

* Microsoft Excel
* Excel Formulas & Functions
* Pivot Tables
* Charts & Visualizations
* Conditional Formatting
* Data Validation
* Data Consolidation

## Process

1. Imported and organized the dataset.
2. Cleaned and validated the data.
3. Applied basic and advanced Excel formulas.
4. Performed calculations using arithmetic, logical, text, and lookup functions.
5. Created summary tables and pivot tables.
6. Consolidated monthly sales data into a single report.
7. Built charts and visualizations for better understanding.
8. Generated insights based on the analyzed data.

## Key Insights

* Identified highest and lowest sales values using Excel functions.
* Calculated total, average, median, and ranked sales performance.
* Consolidated monthly product sales into a single report.
* Analyzed product-wise sales trends across multiple months.
* Created summary reports to support data-driven decision making.
* Improved reporting efficiency through Excel automation and formulas.
